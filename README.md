# tsn-c-stack

A portable C stack for the TSN control plane: the IEEE 1722.1 / Milan ADP, ACMP and MAAP protocol cores.

The cores depend only on the C library. They take no FPGA, register-map or operating-system dependency.

The code arrives from [milan-fpga](https://github.com/kebag-logic/milan-fpga) under [issue #697](https://github.com/kebag-logic/milan-fpga/issues/697).

SRP comes from [lwSRP](https://github.com/kebag-logic/lwSRP), a separate component under its own Apache-2.0 licence.
